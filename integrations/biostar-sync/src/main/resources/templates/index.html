1. BioStar 2 server

2. Premium HRM

The account needs EMPLOYEE:VIEW, ADD and CONFIGURE, ORG:VIEW and ATTENDANCE:EDIT. Create the API key in HRM under Attendance → Sources, for the company chosen below.

3. New employees

Set up the HRM connection first.

This HRM company has no branches, departments, designations, employment categories, which new employees need. Add them in HRM (Organization), then press "Reload groups and HRM lists".

BioStar has no placement or join date, so new employees get these defaults. HR can edit each employee in HRM afterwards; the sync never changes existing employees.

User groups → departments

Only users (and their punches) in groups mapped to a department are synced. Leave leavers, contractors and visitors on "Do not sync".

Set up the BioStar connection to see its user groups.

Punch direction

BioStar's tna_key is the T&A key pressed on the device. Other keys and punches without a key are sent as unknown; HRM then pairs them in time order.

4. Sync

Dates are in the HRM company's time zone. Users are synced first, then the punches in the range. Re-running a range is safe: HRM skips punches it already has.

Automatic sync

Devices that were offline upload their punches later with the original time; each run re-reads this many hours so those are not missed. For longer outages, sync the dates manually above.
